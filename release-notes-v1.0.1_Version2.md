# JARVIS OS v1.0.1

Patch release untuk stabilisasi aplikasi desktop Windows 10/11.

## Perubahan utama
- Perbaikan kestabilan saat aplikasi dibuka di Windows 10/11
- Pengaturan jendela desktop yang lebih aman dan konsisten
- Pembaruan metadata build agar installer dan portable lebih rapi
- Peningkatan kompatibilitas saat menjalankan mockup JARVIS OS dalam mode desktop
- Tuning release pipeline untuk build Windows yang lebih siap didistribusikan

## Catatan
- Versi ini tetap menggunakan mockup UI yang sudah ada di `jarvis_ui_mockup.html`
- Aplikasi siap dikemas menjadi installer `.exe` dan portable `.zip`
- Cocok dipakai sebagai demo desktop / mockup produk

## Build target
- Windows 10
- Windows 11

## Instalasi
1. Download file installer atau portable build
2. Jalankan file installer
3. Ikuti instruksi instalasi
4. Buka aplikasi JARVIS OS dari Start Menu atau Desktop
